# FizzBuzz

Write `fizzbuzz(n)` that returns a **list of strings** for the numbers `1` to `n`:

- multiples of 3 become `"Fizz"`
- multiples of 5 become `"Buzz"`
- multiples of both become `"FizzBuzz"`
- every other number becomes the number as text, like `"7"`

```python
fizzbuzz(5)   # ["1", "2", "Fizz", "4", "Buzz"]
fizzbuzz(0)   # []
```
