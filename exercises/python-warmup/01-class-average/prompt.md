# Class average

Write `average(marks)` so it returns the average of a list of marks, **rounded to 2 decimal places**.

An empty list has an average of `0.0`.

```python
average([70, 80, 90])  # 80.0
average([1, 2, 2])     # 1.67
average([])            # 0.0
```

**Tip:** `round(value, 2)` rounds to two places.
